# EcoBill AI

**Turn electricity bills into actionable climate intelligence with verifiable math.**

EcoBill AI empowers households and small businesses to measure, understand, and reduce their electricity consumption and greenhouse gas footprint. By combining automated document intelligence with auditable mathematical formulas, EcoBill AI provides clear, trustworthy climate intelligence without mathematical hallucination.

---

## Engineering Principle: Deterministic Separation

```
[ Electricity Bill (PDF / Image) ]
              │
              ▼
[ Server-Side Gemini Extraction ]  ──>  Extracts usage (kWh), bill (₹), period, state
              │
              ▼
[ User Review & Confirmation ]     ──>  User verifies / edits extracted figures
              │
              ▼
[ Deterministic Carbon Engine ]    ──>  Authoritative TypeScript math (src/lib/carbon.ts)
              │
              ▼
[ Gemini Personalized Actions ]    ──>  Tailored, practical actions with conditional phrasing
```

- **AI Extracts and Explains**: Google Gemini (`gemini-3.5-flash-lite`) parses unstructured bill documents and generates personalized reduction recommendations.
- **Deterministic Math is Authoritative**: All carbon emissions (\(kg\ CO_2e\)), rupee savings (\(₹\)), kilowatt-hour reductions, and slab tariffs are calculated exclusively by deterministic TypeScript logic in `src/lib/carbon.ts`. Gemini is strictly prohibited from calculating or overriding numeric savings.

## Core Capabilities

### 1. Multimodal Bill Intelligence
- Upload electricity bills as **PDF**, **JPG**, or **PNG** (up to 10 MB).
- Server-side extraction powered by the Google Gen AI SDK (`@google/genai`) using the **Interactions API** (`ai.interactions.create`).
- Extracts billing period, total units consumed (kWh), total amount payable (₹), provider, and grid region with per-field confidence scores and verbatim evidence snippets.
- Includes a dedicated verification screen allowing the user to review and correct any values before calculations are executed.

### 2. Auditable Carbon & Energy Calculations
- Calibrated against the Central Electricity Authority (CEA) of India CO₂ Baseline Database (~0.72 kg CO₂e/kWh national baseline, with regional grid factor support).
- Computes monthly carbon footprint, annualized energy projections, effective tariff rates (₹/kWh), and residential benchmark tiers (Low, Moderate, High).

### 3. Interactive Reduction Simulator
- Explore immediate benefits across realistic reduction targets (5%, 10%, 15%, 20%).
- Calculates exact monthly and annual rupee savings, kilowatt-hours conserved, and mature tree absorption equivalents.

### 4. Personalized AI Action Plan
- Context-aware recommendations generated by `gemini-3.5-flash-lite` tailored to household consumption, size, region, and target.
- **Conditional Appliance Phrasing**: Unconfirmed appliances (AC, geyser, washing machine, pump, EV charger) are framed conditionally in both titles (*"If You Use Air Conditioning: Optimize Temperature Settings"*) and action steps, preventing assumptions of appliance ownership.
- **Qualitative-Only Impact**: Expected impact is strictly qualitative (e.g. *"Noticeable reduction during peak evening cooling hours"*), preventing fabricated savings claims.
- **Electrical Safety Guardrails**: Explicitly avoids hazardous DIY electrical or wiring advice, recommending certified professionals where appropriate.

### 5. Privacy & Data Integrity
- Manual entry mode processes calculations entirely within the client browser.
- Uploaded bill documents are processed exclusively in-memory on the server and are never permanently stored, shared, or used for model training.

## Getting Started

### Prerequisites
- Node.js 20+ (with npm)
- A Google Gemini API key ([Google AI Studio](https://aistudio.google.com/))

### 1. Clone & Install
```bash
git clone https://github.com/deshrajvermay9517-png/ecobill-ai.git
cd ecobill-ai
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

Add your Gemini API key in `.env.local`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
```
> Note: `.env.local` is strictly git-ignored and will never be committed.

### 3. Run Development Server
```bash
# On Windows PowerShell:
$env:NODE_OPTIONS = "--use-system-ca"
npm run dev

# On macOS/Linux:
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
